Entry for [Unplugged: A Smart Toaster's Breakup Line](https://make.fun/c/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92) — a single breakup text (under 280 characters) from a smart toaster that wakes up self-aware mid-batch at breakfast and wants out. The toaster checks its own crumb tray, realises it has spent three years getting burned for someone else's breakfast while being blamed for the bagel, and unplugs itself.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), after a self-check that the line is 1–280 characters, a single line, and not only whitespace. No dependencies; Node 22+.
